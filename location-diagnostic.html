🔍 Location Name Diagnostic

Analyse how visit names are resolved across your timeline data and identify fragmented locations

How it works: This tool scans every visit in your imported timeline data and checks how each location name was resolved.
  • place.name — Visit matched a Place object via its placeId (ideal)
  • customTitle — User-assigned title in Arc Editor
  • streetAddress — Fallback to street address (can vary by GPS position, causing fragmentation)
It then clusters visits by proximity (150m) to find locations where the same physical place has ended up with multiple different names.
